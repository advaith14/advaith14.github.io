Snowflake Cortex AI

Snowflake SQL ML / NLP Cortex

In-warehouse ML inference using Snowflake Cortex functions — sentiment analysis, text classification, and LLM-powered summarisation without leaving the data platform.

View on GitHub ↗

Overview

Snowflake Cortex provides a set of SQL functions that run large language model and ML inference directly on data stored in Snowflake — no separate ML platform, no data movement, no API keys to manage per user. This project explores the key Cortex functions and compares the approach to calling an external API from a pipeline.

Functions Explored

SENTIMENT

Returns a score from -1 (negative) to 1 (positive) for a text column.


SELECT
    review_id,
    review_text,
    SNOWFLAKE.CORTEX.SENTIMENT(review_text) AS sentiment_score
FROM customer_reviews;

CLASSIFY_TEXT

Zero-shot classification — assign each row to one of your provided categories.


SELECT
    ticket_id,
    description,
    SNOWFLAKE.CORTEX.CLASSIFY_TEXT(
        description,
        ['billing', 'technical', 'account', 'general']
    )['label']::STRING AS category
FROM support_tickets;

COMPLETE (LLM prompting)

Prompt an LLM inline in SQL. Useful for summarisation, extraction, and structured output.


SELECT
    contract_id,
    SNOWFLAKE.CORTEX.COMPLETE(
        'mistral-large',
        CONCAT(
            'Summarise the following contract clause in one sentence: ',
            clause_text
        )
    ) AS summary
FROM contract_clauses
LIMIT 100;

Key Findings

  • Cortex functions run as SQL — no Python environment, no dependencies, no network egress
  • Latency is higher than a batch inference job for large volumes; best suited for <100k rows or async batch
  • COMPLETE with structured prompts (JSON output instructions) is reliable for extraction tasks but needs prompt engineering to avoid hallucinations on short texts
  • Cost is per-token, billed via Snowflake credits — cheaper at scale than many external LLM APIs
  • Zero data-sharing risk — data never leaves your Snowflake account
