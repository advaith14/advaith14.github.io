Snowflake Cortex AI

Snowflake SQL ML / NLP Cortex

In-warehouse ML inference using Snowflake Cortex — sentiment analysis, text classification, and LLM-powered summarisation written entirely in SQL, with no external infrastructure.

Overview

Most ML on data warehouse content follows the same awkward pattern: export data, call an external API or inference endpoint, wrangle the results back in. Snowflake Cortex short-circuits that entirely. The functions run inside your Snowflake account — no data leaves, no separate infrastructure to maintain, no API keys to rotate per user.

This project explores where that approach works well (fast iteration on structured text, in-flight classification at load time) and where it has limits (large-volume batch inference, highly customised models).

💬

Sentiment Analysis

Score text columns from -1 to +1 using CORTEX.SENTIMENT — customer reviews, support tickets, survey responses.

🏷️

Zero-Shot Classification

Assign rows to custom categories without training data using CORTEX.CLASSIFY_TEXT.

🤖

LLM Prompting in SQL

Summarise, extract, or transform text using CORTEX.COMPLETE with any of Snowflake's hosted models.

🔒

Zero Data Egress

All inference runs inside your Snowflake account. Data never touches an external API or third-party endpoint.

Functions Explored

Sentiment scoring on review data

SELECT review_id,
       SNOWFLAKE.CORTEX.SENTIMENT(review_text) AS sentiment_score
FROM   customer_reviews;

Zero-shot classification

SELECT ticket_id,
       SNOWFLAKE.CORTEX.CLASSIFY_TEXT(
           description,
           ['billing', 'technical', 'account', 'general']
       )['label']::STRING AS category
FROM   support_tickets;

In-line LLM summarisation

SELECT contract_id,
       SNOWFLAKE.CORTEX.COMPLETE(
           'mistral-large',
           'Summarise in one sentence: ' || clause_text
       ) AS summary
FROM   contract_clauses;

Key Findings

  • Cortex runs as pure SQL — zero Python environment, zero dependencies, zero network egress
  • Latency is higher than dedicated batch inference for very large tables; best under ~100k rows or async
  • COMPLETE with structured output instructions is reliable for extraction tasks with a bit of prompt tuning
  • Per-token cost billed as Snowflake credits — cheaper at scale than most external LLM APIs
